# Changelog — JoJo Brain V0.3.0

## Added

- Living Neural Universe full-screen graph.
- Dependency-vrije springphysics en velocity damping.
- Sleepbare nodes met fysieke reactie via connections.
- Canvas particle field, focusglow, curved connections en moving pulse dots.
- Zoom/focusovergang bij openen van clusters.
- Adaptieve zichtbare subgraph met JoJo als ancestor.
- Volledig uitgewerkte Sport & Health-cluster.
- Garmin-subcluster: Training, Health data en Devices.
- Strava-subcluster: Activities, Segments en Community.
- Mobiele detail bottom sheet.
- Adaptief mobile/reduced-motion performanceprofiel.
- `ENGINE.md`, `ROADMAP.md`, `TESTING.md`, `VERSION_HISTORY.md` en `CONVERSATION_LOG.md`.

## Changed

- Vaste radiale layout vervangen door een hybride canvas/DOM spatial engine.
- UI is nu volledig schermvullend.
- Home en Development zijn visueel secundaire hoofdtakken.
- Architectuurdocumentatie volledig bijgewerkt.
- Cacheversie verhoogd naar `jojo-brain-v0.3.0`.

## Preserved

- PWA-manifest en standalone installatie.
- Appiconen en homescreenondersteuning.
- Offline app-shell.
- GitHub Pages-deployment.
- Veilige lege configuratie voor lokale/private links.

## Security

- Geen tokens, credentials, persoonsgegevens of private netwerkadressen toegevoegd.
- Externe data wordt niet door de service worker gecachet.
